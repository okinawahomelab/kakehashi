How to set up your own YouTube API key

For your own Kakehashi installation: a key enables YouTube search and in-app previews. Without one, browse the curated lists and open videos on YouTube. Website operators should configure their own project and server key; visitors should not enter keys from unrelated projects.

  1. Open Google Cloud Console and select or create a project for your Kakehashi setup.
  2. In APIs & Services, enable YouTube Data API v3.
  3. Open Credentials, choose Create credentials → API key, and restrict the key to YouTube Data API v3 and the website where you use Kakehashi.
  4. Copy the key into the field above and choose Save key. Use Remove key to erase it from this browser.

Google applies a project quota. Keep your key private and use your own project. YouTube API setup guide
